# IronCore — лендинг (инструкция для Claude)

Одностраничный сайт компании IronCore (проектирование защищённых ЦОД). Это демо на GitHub Pages; потом сайт перенесут на WordPress, поэтому код простой и понятный.

Владелец не программист: объясняй коротко, без терминов, отвечай по-русски.

## Порядок работы в каждом чате
1. Прочитай `docs/STATUS.md` (что сделано, какой шаг) и нужный шаг в `docs/roadmap.md`.
2. Тексты бери **только** из нужного раздела `docs/content.md` (читай только его, не весь файл). Не придумывай тексты, цифры, отзывы.
3. Соблюдай `docs/design-rules.md` (никаких признаков ИИ-сайта) и цвета из `docs/brand.md`. После шага 4 — `docs/design-system.md`.
4. Сделай работу, затем: обнови `docs/STATUS.md` (что сделано, что дальше), `git add -A && git commit && git push` в `main`.
5. В конце ответа дай: ссылку на демо, 2–3 строки что изменилось, и **готовое стартовое сообщение для следующего чата**.

## Экономия токенов (важно, лимит маленький)
- Не открывай `docs/tz/*.png` — весь текст уже в `content.md`. Открывай скриншот, только если пользователь просит сверить картинку.
- Не перечитывай файлы, которые уже есть в контексте. Правь точечно (Edit), не переписывай файл целиком.
- Не делай скриншотов, браузерных проверок, установок пакетов, если пользователь не попросил.
- Не плодить отчёты: в конце чата короткий итог.
- Нет картинки — ставь аккуратную заглушку нужного размера и добавь промпт в `docs/image-prompts.md`.

## Техника
- Чистый HTML + CSS + JS, без сборщиков и фреймворков. Шрифты — Google Fonts. Иконки — инлайн SVG.
- `index.html` — вся страница; стили `assets/css/` (`base.css` + по файлу на блок/вариант); скрипты `assets/js/main.js`.
- Секции с id из `content.md`; БЭМ-подобные классы (`.services__card`); CSS-переменные для цветов и отступов.
- Адаптив: 360px, 768px, 1280px+. `prefers-reduced-motion` отключает анимации.
- Форма — заглушка (без отправки), показывает «Спасибо, мы свяжемся с вами».
- Демо: https://d1trepes.github.io/ironcore-landing/ (обновляется через 1–2 минуты после push).
