# Промпты для картинок (Gemini)

К каждому промпту добавлять общий стиль из `docs/brand.md`.
Готовый файл загрузить в `assets/img/` с указанным именем (GitHub → папка `assets/img` → Add file → Upload files → Commit).
Статус: ⬜ нужно сделать · ✅ загружено.

## Первый экран (hero)

⬜ `hero-b-cutaway.webp` (для варианта B, 1920×1080)
```
Cutaway cross-section view of a modern secure data center campus at blue hour: on the left a large two-storey concrete data center building on the ground, in the middle the ground is cut open showing a reinforced underground data hall with server racks lit in cool white, on the right three steel shipping-container modular data centers on a concrete pad. Visible soil and rock layers, cable trenches, cooling units on the roof, perimeter fence. Camera: three-quarter aerial view from the right, 35mm. Dark sky, wet asphalt reflections.
```

⬜ `hero-c-ground.webp`, `hero-c-underground.webp`, `hero-c-container.webp` (для варианта C, 1200×1500, вертикальные)
```
1) Exterior of a modern minimalist data center building made of dark grey concrete and perforated steel panels, overcast daylight, wide plain landscape, vertical composition.
2) Interior of an underground data hall carved into rock: reinforced concrete vault ceiling, rows of black server racks, cold aisle containment, cool white light, vertical composition.
3) Three dark-grey modular container data centers on a concrete pad, cooling units on top, cable trays, early morning light, vertical composition.
```
Вариант A картинок не требует: визуал рисуется в коде (SVG-разрез).
