# План работ по чатам

Один чат = один шаг. Модель указана: **Sonnet** строит по готовой спеке (дёшево), **Opus** только там, где нужны решения.
В начале каждого чата вставить «Стартовое сообщение» из шага. В конце чата Claude обновляет `docs/STATUS.md`, делает commit + push и пишет, какой шаг следующий.

| Шаг | Модель | Что делаем |
|---|---|---|
| 0 | Opus | ✅ Репозиторий, контент ТЗ, правила, спеки hero (этот чат) |
| 1 | Sonnet | Каркас сайта + переключатель вариантов + Hero A |
| 2 | Sonnet | Hero B |
| 3 | Sonnet | Hero C → ссылку отправляем заказчику |
| 4 | Opus | Заказчик выбрал вариант → дизайн-система + спеки блоков 02–11 |
| 5 | Sonnet | Блоки 02 и 03 |
| 6 | Sonnet | Блоки 04 и 05 |
| 7 | Sonnet | Блоки 06 и 07 |
| 8 | Sonnet | Блоки 08–11 (материалы, FAQ, форма, футер) |
| 9 | Sonnet | Адаптив, анимации, финальная полировка, логотип в SVG |
| — | Sonnet | Любые правки: «Поправь блок N: …» |

Стартовое сообщение для любого шага:
```
Шаг N. Репозиторий d1trepes/ironcore-landing. Прочитай CLAUDE.md и docs/STATUS.md, потом сделай шаг N из docs/roadmap.md.
```

## Каркас (делается в шаге 1, до Hero A)
- Чистый HTML/CSS/JS без сборщиков: `index.html`, `assets/css/base.css`, `assets/css/hero-a.css` (b, c), `assets/js/main.js`.
- Шапка, пустые секции-заглушки с id из `content.md` (заголовок раздела + «в работе»), футер, модальная форма (поля из `content.md`).
- **Переключатель вариантов** (`assets/js/main.js` + стили в `base.css`):
  - Плавающая панель внизу слева: «Первый экран: A B C» и переключатель «Подписи».
  - Внутри `#hero` три блока `.hero.hero--a/b/c`; виден один. Подпись — маленькая метка в углу hero «Вариант A — Чертёж»; «Подписи» её скрывают/показывают.
  - Состояние в URL: `?hero=b&labels=0`, чтобы отправлять заказчику прямую ссылку. `?demo=0` прячет панель целиком.
  - Клавиши 1/2/3 переключают варианты.
- Шапка и футер общие, но цвета шапки берутся из CSS-переменных варианта (`.is-hero-a` на `<body>` и т.п.).

## Общее для всех hero
Контент: H1, подзаголовок, строка форматов, две кнопки, шапка — из раздела 01 `content.md`. Строка форматов без точек-разделителей. Высота: минимум 100vh − шапка, на мобильном текст сверху, визуал снизу. Цвета синий/красный из `brand.md`.

## Hero A — «Чертёж» (светлый, инженерный)
- Фон почти белый `#F7F8FA` с тонкой сеткой чертежа (линии 1px `#1E3A8A` 6% прозрачности, шаг 24px, каждая 4-я ярче).
- Слева (5 из 12 колонок): H1 крупно (64–80px), подзаголовок, форматы отдельными строками с короткой синей линией перед каждой (Классические / Модульные / Контейнерные / Подземные), кнопки: основная синяя «Обсудить проект», вторичная текстовая со стрелкой «Наши решения».
- Справа (7 колонок): **SVG-разрез** в изометрии, линиями: здание ЦОД на земле, под линией грунта — заглублённый зал со стойками, рядом 2–3 контейнера. Линии синие 1.5px, грунт — штриховка, ядро (серверный зал под землёй) залито красным. Размерные линии и выноски моноширинным шрифтом: «IT 0,5–15 МВт», «−12,0 м», «N+1».
- Анимация: при загрузке линии разреза прорисовываются (stroke-dashoffset, ~1.6с), выноски появляются после. Курсор над визуалом слегка смещает слои (параллакс 4–8px).
- Шрифты: заголовки **Onest** 600, текст **Onest** 400, цифры/выноски **JetBrains Mono** (обе с кириллицей, Google Fonts).

## Hero B — «Ночной объект» (тёмный, фотореализм)
- Фон графит `#0E1117`, на всю ширину картинка `assets/img/hero-b-cutaway.webp` (промпт в `image-prompts.md`; до загрузки — тёмная заглушка с подписью). Слева тёмная подложка-градиент только для читаемости текста (от `#0E1117` к прозрачному).
- Текст слева, белый. H1 72–88px, подзаголовок светло-серый `#B7BFCC`.
- Форматы — три «пина» прямо на картинке (точка + тонкая линия + подпись: «Классический ЦОД», «Подземный ЦОД», «Контейнерный ЦОД»), стоят над соответствующими частями рендера; появляются по очереди.
- Кнопки: основная красная «Обсудить проект», вторичная с белой обводкой «Наши решения».
- Снизу полоса из 3 цифр (табличный шрифт): «0,5–15 МВт», «50–1 500 стоек», «4 формата исполнения» с тонкими разделителями-линиями.
- Анимация: медленный zoom картинки 1.00→1.05 за 12с, пины появляются после текста.
- Шрифты: **Manrope** 700 для заголовков, **Inter** 400 текст.

## Hero C — «Редакционный» (светлый, типографика + триптих)
- Фон тёплый светло-серый `#EEEDEA`, текст графит.
- Верхняя часть: H1 на всю ширину, очень крупно (96–120px на десктопе), в две строки, «проекта» — синим. Под ним в две колонки: слева подзаголовок, справа кнопки.
- Нижняя часть: **триптих** из трёх вертикальных фото (`hero-c-ground/underground/container.webp`): «На земле», «Под землёй», «В контейнерах». Подпись под каждым + короткий параметр моноширинным («до 30 000 м²», «заглубление по расчёту», «от 1 контейнера»). Средняя картинка чуть выше остальных. При наведении фото слегка приближается, подпись подчёркивается красной линией.
- Кнопки: основная графитовая «Обсудить проект», вторичная подчёркнутая ссылка «Наши решения».
- Анимация: строки H1 появляются построчно (маска снизу), триптих — с небольшой задержкой.
- Шрифты: **Geologica** 600 для H1, **Golos Text** 400 текст, **JetBrains Mono** для параметров.

## Шаг 4 (Opus) — что сделать
1. Записать выбранный вариант в `docs/STATUS.md`, удалить два других hero и переключатель (или оставить переключатель скрытым — по желанию).
2. Создать `docs/design-system.md`: шрифты, размеры, цвета, отступы, кнопки, карточки, способы раскрытия контента — из выбранного hero.
3. Для каждого из шагов 5–8 записать в этот файл (ниже) короткую спеку раскладки блоков, с разными приёмами подачи (вкладки, аккордеон, раскрывающиеся карточки, карусель, таймлайн, таблица), и дописать промпты картинок в `image-prompts.md`.
